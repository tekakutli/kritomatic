# Project map

This directory holds two independent consumers of the room model:
the **boxes playground** (interactive, browser) and the **floor-plan
renderer** (CLI, one-shot SVG/PNG). Both read the same sidecars that
`shared/room.py` produces.

    playgrounds/
    ├── shared/                        the room model and its outputs
    │   ├── room.py                    generator (run manually)
    │   ├── playground_fonts.py        font-stack source (all playgrounds)
    │   ├── room_walls.json            read by boxes, floor_plan, cable
    │   ├── room_dimensions.json       read by floor_plan
    │   ├── room.step                  build artifact (currently unread)
    │   └── room.stl                   build artifact (currently unread)
    │
    ├── room/                          THIS directory
    │   ├── boxes_playground.py        browser, interactive
    │   └── floor_plan.py              CLI, writes floor_plan.svg/.png
    │
    └── cable/                         separate project
        └── cable_playground.py        reads shared/room_walls.json too

## Run

    cd playgrounds/shared && python room.py
    cd ../room            && python floor_plan.py
    cd ../room            && python boxes_playground.py

The `cable/` project is independent — see `playgrounds/cable/README.md`.

## What lives where

`shared/` — the room model and its outputs. `room.py` emits
`room_walls.json`, `room_dimensions.json`, `room.step`, `room.stl`
next to itself. `playground_fonts.py` is the single font-stack source
for every playground in `playgrounds/`.

`room/` — two consumers:

- **boxes_playground** — browser UI, drag rectangles onto the plan
  view. Reads `shared/room_walls.json` via `boxes_geometry.py`.
- **floor_plan** — CLI renderer, writes `floor_plan.svg` + `.png`.
  Reads `shared/room_walls.json` and `shared/room_dimensions.json`
  via `floor_plan_geometry.py`.

Both add `../shared` to `sys.path` for `playground_fonts`, and resolve
the JSON paths by `__file__` so they work from any working directory.

## Removed in the cable-extraction refactor

Every cable-playground module (`cable_*.py`, `pg_arrows_*.py`,
`pg_export_*.py`, `pg_core.py`, `pg_dispatch.py`, `pg_edit.py`,
`pg_i18n.py`, `pg_navigation.py`, `pg_panel.py`, `pg_route.py`,
`pg_ruler.py`, `pg_snap.py`, `pg_view_*.py`), plus `room_layout.json`
and `leader_optimizer/`, now lives under `playgrounds/cable/`. The
`quiet.py` stderr-silencer moved with them — only `cable_geometry.py`
imported it; `room.py` uses its own inline `_quiet()`.
